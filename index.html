How a cohort runs

Structured like the pipelines you'll build.

Every stage has to pass before the next one runs — same as CI/CD.

  1. learn ✓ pass

    Foundations

    Linux, networking, Git, and cloud fundamentals — the layer everything else stands on.

  2. build ✓ pass

    Infrastructure as Code

    Provision real environments with Terraform. Break them. Fix them. Understand why.

  3. deploy ● running

    CI/CD & DevSecOps

    Pipelines, secrets management, container security, and the checks that gate a release.

  4. ship ○ queued

    Capstone & Portfolio

    Design and deploy a production-style system end to end. This is what you show employers.
